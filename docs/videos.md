# 動画と絵

`public/anim/` の動画は Gemini Omni 1.2 Flash、止まった絵とお題の絵は Nano Banana 2 で作りました。

| ファイル | 流れる場面 |
|---|---|
| wake_up.mp4 | 最初にロボが起きる（読み込み中はくり返し流す） |
| idle.mp4 | 手順を待っている |
| playing.mp4 | 手順を実行している |
| nigiru_barehand.mp4 | 道具の失敗（素手でにぎる） |
| onigiri_crack.mp4 | 順番の失敗（にぎったあとにうめを押しこむ） |
| ume_drop_table.mp4 | どこにの失敗（うめがテーブルに転がる） |
| tilt_head.mp4 | 首をかしげる（読み取れなかったときなど） |
| success.mp4 | 完成 |

動画が無いときと読み込み中は `still.jpg`（止まった絵）を出します。
